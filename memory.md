# Manga AI Agent Memory

**ВАЖНО**: Этот файл содержит критические правила (habits) для пайплайна перевода. Перед началом любых задач, агент обязан следовать этим правилам.

## 1. Клининг (Inpainting)
- **ЗАПРЕЩЕНО**: Использовать `cv2.rectangle` для заливки бабблов (это ломает края и оставляет артефакты).
- **ПРАВИЛО**: Использовать маскирование пикселей текста (`cv2.threshold`) и `cv2.inpaint(..., cv2.INPAINT_TELEA)` для аккуратного удаления только букв.

## 2. Тайпсеттинг (Typography)
- **ЗАПРЕЩЕНО**: Добавлять `*[ ]*` или другие "айтишные" теги к SFX/обычному тексту.
- **ЗАПРЕЩЕНО**: Использовать шрифты без поддержки кириллицы. Только `comicbd.ttf`, `arialbd.ttf`, `segoeuib.ttf`.
- **ПРАВИЛО**: Подбирать контрастный цвет текста (черный текст на светлом фоне, белый текст на темном фоне баббла).

## 3. Архитектура и Автоматизация
- **ПРАВИЛО**: Кнопка `Auto-translate` во фронтенде должна быть жестко привязана к реальному пайплайну в `main.py` (`fast_reprocess.py` или `MangaPipelineService`). Не использовать fake/mock статусы.
- **ПРАВИЛО**: Сохранять оригинальные координаты `boxes` бабблов из OCR, не расширять их искусственно за пределы логических границ.
